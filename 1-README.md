# Portfolio de Jose Manuel

Web personal publicada en GitHub Pages. HTML, CSS y JavaScript sin dependencias de ejecución.

## Desarrollo

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático. Los estilos están en `style.css` y las mejoras progresivas en `app.js`.

El contenido y la navegación siguen disponibles sin JavaScript. Las animaciones respetan `prefers-reduced-motion`.

## CV

Mientras no haya un PDF listo para publicar, los botones "Solicitar CV" abren un correo. Para activar la descarga:

1. Revisa qué datos personales quieres hacer públicos y añade el PDF como `assets/cv-jose-manuel.pdf`.
2. Cambia los dos enlaces "Solicitar CV" por `href="assets/cv-jose-manuel.pdf" download` y el texto "Descargar CV".
3. Verifica la descarga en escritorio y móvil.

No añadas un PDF sin revisar: todos los archivos de este repositorio son públicos.

## Despliegue

GitHub Pages publica la rama configurada en Settings > Pages. Las propuestas en otras ramas no cambian la web pública hasta que se integran en esa rama.

La imagen para enlaces sociales está en `assets/social-preview.png`. El favicon está en `assets/favicon.svg`.
