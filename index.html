PoolBook

De elegir un carril a confirmar una reserva.

Aplicación para gestionar reservas de una piscina. Calendario interactivo, roles de usuario y administrador, bonos de sesiones y un asistente de IA con Groq.

Consulta disponibilidad→ Valida las reglas→Confirma y consume el bono

Lo que hay detrás

  • Una misma validación. Calendario y asistente usan las reglas de horario, límite diario y capacidad por carril.
  • Bonos en orden de caducidad. Consumo FIFO con transacciones y bloqueo de filas para evitar descuentos duplicados.
  • Acceso según el rol. Policies y permisos para separar las reservas propias de la gestión administrativa.
  • Tests de regresión. Reglas de reserva, bonos y corrección de un problema de zona horaria.

Laravel · PHP · MySQL · FullCalendar · Groq API
